# 桌面应用程序开发计划

## 技术方案选择

使用 **Wails v2** 框架构建桌面应用程序，原因如下：

* 原生支持Go后端 + Web前端架构

* 自动将前端编译并嵌入到单个.exe文件中

* 跨平台支持（Windows、macOS、Linux）

* 内置进程间通信机制

* 轻量级，启动速度快

## 开发阶段规划

### 阶段1：项目初始化和分支管理

1. 创建新分支 `feature/desktop-app`
2. 安装Wails CLI工具
3. 初始化Wails项目结构
4. 提交初始化代码

### 阶段2：后端核心逻辑实现

1. 将现有Go后端代码迁移到Wails项目
2. 实现Go绑定方法，供前端调用
3. 添加系统操作和生命周期管理
4. 实现与Python模块的通信接口
5. 提交后端代码

### 阶段3：前端界面开发

1. 将现有Vue前端代码迁移到Wails项目
2. 配置Vue 3 + TypeScript环境
3. 实现主窗口布局和导航
4. 集成ECharts图表组件
5. 实现股票数据可视化功能
6. 添加技术指标选择和时间周期选择
7. 提交前端代码

### 阶段4：Python模块集成

1. 创建Python子进程管理器
2. 实现Go与Python的通信管道
3. 封装Python量化分析功能
4. 添加错误处理和超时机制
5. 提交Python集成代码

### 阶段5：构建和打包

1. 配置Wails构建脚本
2. 设置Windows交叉编译
3. 优化应用大小和启动时间
4. 测试.exe文件独立运行
5. 创建安装程序（可选）
6. 提交构建配置

### 阶段6：测试和优化

1. 在Windows系统上进行完整测试
2. 验证无依赖运行
3. 测试所有功能模块
4. 性能优化
5. 修复发现的bug
6. 最终提交和合并到main分支

## 项目结构预览

```
financial_toolbox/
├── wails.json                    # Wails配置文件
├── main.go                      # Wails入口文件
├── app.go                       # 应用程序逻辑
├── backend/                     # Go后端代码
│   ├── bind/                   # Wails绑定方法
│   ├── service/                 # 业务逻辑
│   ├── model/                  # 数据模型
│   └── python/                # Python集成
├── frontend/                    # Vue前端代码
│   ├── src/
│   │   ├── components/         # 组件
│   │   ├── views/             # 页面
│   │   ├── assets/            # 静态资源
│   │   └── wailsjs/          # Wails生成的绑定
│   ├── package.json
│   └── vite.config.ts
├── build/                      # 构建脚本
│   ├── build.bat              # Windows构建脚本
│   └── build.sh              # Linux/Mac构建脚本
└── dist/                      # 构建输出
    └── financial-toolbox.exe   # 最终可执行文件
```

## 关键技术点

1. **进程间通信**：使用Wails内置的IPC机制
2. **Python集成**：通过exec.Command启动Python进程，使用stdin/stdout通信
3. **资源嵌入**：使用embed包将前端资源嵌入Go二进制
4. **窗口管理**：使用Wails的窗口API实现原生GUI
5. **图表优化**：使用ECharts的按需加载减少体积

## Commit计划

每个阶段完成后进行详细commit：

* `feat: 初始化Wails项目结构`

* `feat: 实现Go后端核心逻辑和绑定`

* `feat: 实现Vue前端界面和ECharts集成`

* `feat: 集成Python量化分析模块`

* `build: 配置构建脚本和交叉编译`

* `test: 完成Windows系统测试和优化`

* `chore: 合并到main分支`
